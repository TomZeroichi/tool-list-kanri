# TOM eBay Growth v1.0.0

12ヶ月間のeBay成長ロードマップを管理するスマホ対応PWAです。

公開パス: https://tomzeroichi.github.io/tool-list-kanri/ebay-growth/

## 機能

- STEP1: 1〜3ヶ月｜月利10万円・評価10
- STEP2: 4〜6ヶ月｜月利30万円・評価50
- STEP3: 7〜9ヶ月｜月利50万円・評価100
- STEP4: 10〜12ヶ月｜月利100万円・評価200
- 12ヶ月の目標・実績入力、チェックリスト、利益シミュレーター
- JSONバックアップ・復元
- 端末内のlocalStorageに保存。クラウド同期はありません。

## 配置

既存ツールリストのルートは変更せず、ebay-growth/だけを独立配置しています。
ホーム画面に追加するとPWAとして利用できます。GitHub Pagesの公開設定が必要です。

## 注意

GitHub Pagesは公開サイトです。ソースコードと固定の目標数値は公開されます。ユーザーが入力する実績・メモはブラウザのlocalStorage内にのみ保存され、GitHubには送信されません。ブラウザデータの削除や端末変更で消えるため、JSONバックアップを推奨します。
